# ✅ Simple To-Do List App

A terminal-based task manager built in Python that lets you add, view, and delete tasks. Tasks are saved to a file so they persist even after you close the app.

## Features
- Add new tasks
- View all current tasks
- Delete tasks by number
- Tasks saved automatically to `tasks.txt`
- Data persists across sessions

## How to Run
1. Make sure Python is installed
2. Download `todo_app.py`
3. Open terminal and run:
```bash
python todo_app.py
```
4. Use the menu to manage your tasks

## Tech Used
- **Language:** Python
- **Concepts:** File handling, lists, functions, loops, input validation
